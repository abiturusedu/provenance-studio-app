# Provenance Studio

Конспекты книг и статей в виде базы знаний: книги и главы, понятия, утверждения автора, примеры, свои мысли и вопросы —
со связями между ними, графом и разбором текста с помощью ИИ. У каждого факта из разбора видно происхождение:
цитата и страница, откуда он взят.

Здесь лежат только готовые программы. Есть две версии.

| | Где работает | Как начать |
| --- | --- | --- |
| **Сайт** | в браузере (Chrome, Edge; Firefox и Safari — пока не проверены) | открыть https://abiturusedu.github.io/provenance-studio-app/ |
| **Настольная версия** | Windows 10 и 11 | скачать установщик в [Releases](../../releases/latest) |

## Сайт

Ничего устанавливать не нужно. База «Конспекты» создаётся при первом открытии.

- **Данные хранятся только в вашем браузере на вашем компьютере.** Сервера у приложения нет, на сервер ничего не отправляется.
  Другой браузер или другой компьютер — это другие данные.
- **Скачивайте копию базы время от времени:** меню с названием базы вверху слева → «Скачать копию базы».
  Если очистить данные сайта в браузере или работать в приватном окне, базы пропадут. На другом компьютере копия загружается
  через «Мои базы…» → «Загрузить файл базы…».
- Сайт открывается в одной вкладке одновременно — так база не повредится.
- Нет шаблона «История», видео и аудио. Загрузка статьи «По ссылке» с большинства сайтов не работает: браузер не даёт одному
  сайту читать страницы другого — скопируйте текст и вставьте его во вкладке «Вставить текст».

## Настольная версия для Windows

1. Откройте [последний выпуск](../../releases/latest) и скачайте `Provenance-Studio-Setup-<версия>.exe`.
2. Запустите. Windows может показать «Система Windows защитила ваш компьютер» — нажмите **«Подробнее» → «Выполнить в любом случае»**:
   у установщика нет платной цифровой подписи.
3. Обновления приходят сами: при запуске приложение проверяет, нет ли новой версии, скачивает её и предлагает
   «Перезапустить и обновить». Номер версии и «Проверить обновления» — в меню с названием базы.

Базы лежат в `Документы\Provenance Studio`, настройки — в `%APPDATA%\Provenance Studio`; при обновлении и переустановке они не трогаются.
Файл базы из настольной версии можно загрузить на сайт и наоборот.

## ИИ и ключи API

- Разбор текста с ИИ — по желанию. Нужен свой ключ API: «Меню» (внизу слева) → «Настройка ИИ» → провайдер → ключ → «Проверить соединение».
- Ключ хранится только на вашем компьютере (в настольной версии — в защищённом хранилище Windows, на сайте — в браузере),
  не в файле базы, и отправляется только провайдеру.
- На сайте запросы идут из браузера прямо к провайдеру. Claude (Anthropic) такие запросы принимает; про остальных
  подскажет «Проверить соединение». Подойдёт и свой сервер с OpenAI-совместимым API (например, Ollama).
- ИИ только предлагает записи и связи с цитатами; в базу попадает лишь то, что вы утвердите на экране проверки.
